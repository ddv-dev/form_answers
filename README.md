# Модуль «Ответы на результаты веб-форм» (`form.answers`)

Модуль для 1С-Битрикс: Управление сайтом. Позволяет администратору оставлять
ответы (комментарии) на результаты штатных веб-форм и выводить их на сайте.

## Что делает

- В карточке результата веб-формы (страница «Редактирование результата»)
  добавляет вкладку **«Ответы»**.
- Во вкладке — штатный визуальный HTML-редактор Битрикса (визуальный / HTML /
  текст), кнопка сохранения и список уже оставленных ответов с возможностью
  редактирования и удаления.
- Ответы хранятся в отдельном инфоблоке; для каждой формы вывод вкладки
  включается отдельно галочкой в настройках модуля.

## Требования

- 1С-Битрикс с установленными модулями: **main**, **form** (веб-формы),
  **iblock** (инфоблоки), **fileman** (визуальный редактор).
- В настройках PHP включён `short_open_tag` (файлы модуля используют `<?`).

## Установка (штатными средствами Битрикс)

1. Скопируйте каталог модуля на сервер так, чтобы он оказался по пути:

   ```
   /bitrix/modules/form.answers/
   ```

   (Также поддерживается размещение в `/local/modules/form.answers/`.)
   Внутри должны лежать `include.php`, `options.php`, каталоги `admin/`,
   `install/`, `lang/`.

2. В админке: **Настройки → Настройки продукта → Модули**. Найдите в списке
   **«Ответы на результаты веб-форм»** и нажмите **Установить**.

   При установке модуль автоматически:
   - регистрирует обработчик события `main / OnAdminTabControlBegin`
     (через него добавляется вкладка «Ответы»);
   - создаёт инфоблок для хранения ответов (тип и код `form_answers`) со
     свойствами `ID_RESULT` и `ID_FORM`. Если инфоблок уже существует
     (например, после переустановки) — переиспользует его вместе с данными;
   - копирует свои страницы (`form_answers_admin.php`,
     `form_answers_settings.php`) в `/bitrix/admin/`.

3. **Включите ответы для нужных форм.** Откройте настройки модуля:
   **Настройки → Настройки продукта → Модули → «Ответы на результаты
   веб-форм» → Настройки** (либо пункт меню *Сервисы → Ответы на формы →
   Настройки модуля*). Отметьте галочками формы, для которых нужна вкладка
   «Ответы», и сохраните.

Никаких дополнительных скриптов запускать не нужно — установка выполняется
полностью штатным мастером.

## Как пользоваться

1. Перейдите в результаты нужной веб-формы: **Сервисы → Веб-формы →
   Результаты**, откройте любой результат на редактирование.
2. Выберите вкладку **«Ответы»**.
3. Введите ответ в редакторе и нажмите **«Сохранить»**. Пустой ответ не
   сохраняется. Существующие ответы показаны ниже — их можно редактировать
   и удалять.

## Вывод ответа на сайте

Для вывода ответов на публичной странице (например, на детальной странице
отзыва) подключите модуль и вызовите метод:

```php
if (CModule::IncludeModule('form.answers')) {
    // $resultId — ID результата формы, $formId — ID веб-формы
    $answers = CFormAnswers::getAnswers($resultId, $formId);

    foreach ($answers as $answer) {
        // Тип текста ответа: 'html' или 'text'
        if (($answer['DETAIL_TEXT_TYPE'] ?? 'html') === 'html') {
            echo $answer['~DETAIL_TEXT'];                 // готовый HTML
        } else {
            echo nl2br(htmlspecialcharsbx($answer['~DETAIL_TEXT']));
        }
    }
}
```

`~DETAIL_TEXT` (с тильдой) — «сырой», неэкранированный текст; для типа `html`
его выводят как есть.

## Удаление

**Настройки → Настройки продукта → Модули → «Ответы на результаты веб-форм» →
Удалить**. Удаляются обработчик события, скопированные страницы админки и
настройки модуля. Инфоблок с ответами при удалении **не стирается** — данные
сохраняются и подхватятся при повторной установке.

## Структура файлов

```
form.answers/
├── include.php                     Класс CFormAnswers + обработчик вкладки
├── options.php                     Страница настроек модуля (галочки форм)
├── admin/
│   ├── form_answers_admin.php      Страница вкладки «Ответы» (копируется в /bitrix/admin/)
│   ├── form_answers_settings.php   Альтернативная страница настроек (копируется в /bitrix/admin/)
│   └── menu.php                    Пункт админ-меню (подхватывается ядром на месте)
├── install/
│   ├── index.php                   Установщик (DoInstall / DoUninstall)
│   ├── version.php                 Версия модуля
│   ├── step1.php / unstep1.php     Экраны установки/удаления
│   └── ...
└── lang/                           Языковые файлы
```

## Инфоблок ответов

- Тип инфоблока: `form_answers`, код инфоблока: `form_answers`.
- Свойства:
  - `ID_RESULT` — ID результата формы;
  - `ID_FORM` — ID веб-формы.
- Текст ответа хранится в поле `DETAIL_TEXT` (тип — в `DETAIL_TEXT_TYPE`).
